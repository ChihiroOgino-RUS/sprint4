# Sprint 4 — Автотесты для Яндекс Самокат

Учебный проект по автоматизации тестирования. Написаны автотесты для сервиса [Яндекс Самокат](https://qa-scooter.praktikum-services.ru/).

## Что тестируем

- **FAQ-аккордеон** — проверка, что при клике на вопрос открывается правильный ответ (8 вопросов)
- **Позитивный сценарий заказа** — полный флоу от нажатия кнопки «Заказать» до сообщения об успешном оформлении (2 точки входа × 2 набора данных)

## Стек

- Java 11
- JUnit 4
- Selenium 4
- WebDriverManager

## Запуск

```bash
mvn test
```

## Браузеры

Тесты запускаются в Google Chrome и Mozilla Firefox. WebDriverManager автоматически скачивает нужные драйверы.

## Известная проблема

В Chrome заказ не оформляется — известный баг учебного сервиса. Тесты заказа в Chrome ожидаемо падают. В Firefox все тесты проходят.
